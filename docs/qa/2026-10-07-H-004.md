## 2. Hallazgos

| ID | Severidad | Responsable | Hallazgo | Resultado esperado |
|---|---|---|---|---|
| **QA-009** | **Alta** | Frontend | El reboot de Bootstrap convierte `body { margin: 0; background-color: var(--bs-body-bg); … }` en una regla sobre el propio contenedor: `:is(.ep-app,.ep-public){ …; background-color: var(--bs-body-bg); margin: 0 }`. En wp-admin el contenedor es `<div class="wrap ep-app">` y la hoja del plugin carga después de la de WordPress, así que con la misma especificidad (0,1,0) **anula `.wrap { margin: 10px 20px 0 2px }`**. **Escenario:** cualquier pantalla de administración (la primera será H-104) se pegaría al menú lateral, sin margen derecho, y se vería como una caja blanca sobre el fondo gris del panel. En la intranet, el widget también fuerza fondo blanco y anula el margen lateral que ponga el tema. | El contenedor conserva los márgenes de `.wrap` y el fondo de su entorno; el reboot solo aporta tipografía y color de texto (que `.ep-app` y `.ep-public` ya definen). Agregar a `layout-css.test.js` una verificación de que ninguna regla de la hoja compartida declare `margin` ni `background*` sobre el contenedor sin descendiente. |
| QA-010 | Media | Frontend | `core/i18n.js` y `core/timing.js` (portados de SGP) no tienen pruebas: 0 % de cobertura. Cobertura total de JS: 57,9 %. | Pruebas de `__`, `_n` y `sprintf` (con y sin `wp.i18n`) y de `debounce` (`cancel`, `flush`) y `prefersReducedMotion`. |
| QA-011 | Baja | Frontend | `pages/public.js` (línea 39): si el nombre del widget no está en `WIDGETS`, el encadenamiento opcional no hace nada y el contenedor queda para siempre en «Cargando…» con `aria-busy="true"`. Hoy no se alcanza porque no hay shortcodes registrados. | Quitar `aria-busy` y mostrar un aviso (o al menos `console.warn`) para widgets desconocidos. Corregir antes de H-302/H-304. |
| QA-012 | Info | CI (H-005) | En Windows, Node solo respeta `TZ=UTC`: no se pudo simular localmente una zona con desplazamiento positivo. | El CI (Linux) corre `tests/js/core/date.test.js` con `TZ=UTC`, `America/Bogota`, `Asia/Tokyo` y `Pacific/Kiritimati`. |
| QA-013 | Info | QA (cierre de fase) | `@wordpress/env` 11.17 responde en Node 20, pero npm avisa que sus dependencias `@php-wasm/*` piden Node 24. | Confirmar `wp-env start` al ejecutar las pruebas de integración del cierre del Sprint 0 (QA-008). |
